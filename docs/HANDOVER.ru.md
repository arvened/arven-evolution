# Передача проекта: что есть в репозитории

Версия 0.1.0, 28.09.2026.

## Коротко

Рабочий прототип сервиса самооценки на соответствие EU AI Act и GDPR. Компания заполняет анкету, сервис определяет класс риска каждой ИИ-системы, перечисляет применимые обязанности со ссылками на статьи и выдаёт список действий по приоритету. Дополнительный модуль Fusion проверяет privacy notice по ст. 13 GDPR сразу несколькими LLM.

## Что изменилось по сравнению с прежней версией

Прежняя версия (июнь 2026) не компилировалась. Все оценки в ней были вписаны в код константами, а модуля LLM не было вовсе. Она заменена полностью. История коммитов сохранена.

Все метрики из прежнего README удалены, потому что код не мог их дать: «91% точности», «$0.227 за аудит», «52% экономии», «99.9% uptime», «574 паттерна», «6 741 строка», «23 таблицы».

## Что работает и проверено

- Движок AI Act: запрещённые практики, high-risk (включая исключение ст. 6(3)), обязанности провайдера и деплоера, прозрачность ст. 50, GPAI.
- Движок GDPR: обязанности контролёра и процессора, DPIA, DPO, трансферы, представитель в ЕС.
- Прозрачный расчёт оценки. Вопрос без ответа никогда не засчитывается как выполненный.
- HTTP API, CLI, отчёты в JSON и Markdown.
- 84 автоматических теста, проверка типов, CI на GitHub Actions (включая сборку Docker-образа).

## Что НЕ проверено

- **Юридическое содержание** правил не проверено юристом. Это первое, что нужно сделать до работы с клиентами.
- **Fusion не запускался на реальных API.** Нужны ключи вендоров. Адаптеры написаны по документации и покрыты тестами с имитацией ответов.
- **Docker-образ** собирается в CI на GitHub. Локально при разработке он не собирался.
- Метрик точности пока нет. Их можно получить только прогоном на размеченных реальных документах.

## Следующие шаги

```bash
node src/cli/audit.ts examples/hr-screening-saas.json
```

Нужен Node.js 22.18+. Установка зависимостей не требуется.
